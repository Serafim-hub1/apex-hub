# APEX Hub — командный центр клуба

Веб-приложение для команды APEX (Серафим, Кузьма, Антон): задачи, календарь, база знаний, оплаты и посещаемость из Google-таблицы, push-напоминания и утренний список задач. Ставится на телефон как приложение (PWA), открывается с любого устройства, стоит 0 ₽.

## Из чего состоит

```
Телефон / компьютер  ──  APEX Hub (React PWA)  ──  GitHub Pages и/или Firebase Hosting
        │                     │
        │                     ├── Firebase Auth ........ вход и «запомнить устройство»
        │                     ├── Cloud Firestore ...... задачи, события, страницы (живая синхронизация + офлайн)
        │                     └── Apps Script (Google) . мост к таблице клуба
        │                                                  └── каждые 5 минут: напоминания и утренний список
        └──── push ◄── Firebase Cloud Messaging ◄─────────┘   (+ по желанию дубль в Telegram)
```

| Что | Где живёт | Бесплатный лимит |
|---|---|---|
| Сайт-приложение | GitHub Pages (публичный репозиторий) или Firebase Hosting | хватает с большим запасом |
| Вход, база | Firebase, тариф Spark | 50 000 чтений и 20 000 записей в сутки, 1 ГБ |
| Push | Firebase Cloud Messaging | без ограничений |
| Таблица и планировщик | Google Apps Script | 90 минут работы триггеров в сутки — используем ~20 |

Почему так, а не Supabase: Supabase стоит за Cloudflare, а российские провайдеры с июня 2025 режут ответы Cloudflare до 16 КБ — без VPN приложение бы падало. Всё, что здесь использовано, работает через инфраструктуру Google. Плюс бесплатный Supabase засыпает после 7 дней простоя, Firebase — нет.

## Разделы

- **Сегодня** — задачи на день и просрочки, расписание, должники по оплатам, нагрузка команды.
- **Задачи** — три вида как в Notion: список по срокам, канбан-доска с перетаскиванием, таблица с правкой прямо в ячейке. Исполнители, приоритет, направление, чек-лист, напоминание. Быстрый ввод фразой: `Позвонить в школу 121 завтра в 15:00 @кузьма !`.
- **Календарь** — тренировки, игры, встречи, дедлайны и задачи со сроком. Повторяющиеся события (каждую неделю / через неделю).
- **Клуб** — данные из Google-таблицы: статусы абонементов, «Внести оплату» (пишет в «Журнал оплат»), посещаемость ✓ ✕ У (пишет в «Посещаемость — …»), воронка заявок (лист «Заявки»), долги по лиге.
- **База знаний** — страницы с подстраницами: регламенты, прайс, шаблоны сообщений, планы тренировок. Markdown, чек-листы, таблицы.
- **⌘K / Ctrl+K** — поиск по всему и быстрые действия. **N** — новая задача.

Без ключей Firebase приложение запускается в демо-режиме: данные хранятся в браузере. Так можно всё потрогать до настройки.

## Настройка (≈40 минут, один раз)

### 1. Firebase

1. [console.firebase.google.com](https://console.firebase.google.com) → «Создать проект» (например, `apex-hub`). Google Analytics можно выключить.
2. **Authentication** → «Начать» → способ входа **Email/Password** → включить.
   Вкладка **Users** → «Add user» три раза: почта и пароль для Серафима, Кузьмы и Антона.
3. **Firestore Database** → «Создать базу» → регион `europe-west3 (Frankfurt)` → режим «production».
   Вкладка **Rules** → вставьте содержимое `backend/firestore.rules`, впишите туда три почты → «Опубликовать».
4. **Project settings** (шестерёнка) → **General** → «Ваши приложения» → значок `</>` → зарегистрируйте веб-приложение. Скопируйте `apiKey`, `authDomain`, `projectId`, `storageBucket`, `messagingSenderId`, `appId`.
5. **Project settings → Cloud Messaging** → «Web Push certificates» → **Generate key pair**. Это `VITE_FIREBASE_VAPID_KEY`.
6. **Project settings → Service accounts** → **Generate new private key**. Скачается JSON — он понадобится в шаге 2. Никуда его не публикуйте.

> Если консоль Firebase не открывается из России, зайдите один раз через VPN. Само приложение потом работает без него.

### 2. Apps Script (мост к таблице и напоминания)

1. Откройте Google-таблицу клуба → **Расширения → Apps Script**.
2. Если в проекте уже есть ваш код (например, `onEdit` для «Реестра ID»), **не трогайте его**. Слева «Файлы» → «+» → «Скрипт» → имя `APEX_Hub` → вставьте туда весь `backend/apps-script/Code.gs` → Ctrl+S. Весь код APEX спрятан внутри `APEX_HUB`, наружу выходят только `doPost`, `doGet`, `apexSetup`, `apexTick`. Если в старом коде уже есть свои `doGet` или `doPost`, напишите — разведём.
3. **Параметры проекта** (шестерёнка) → «Часовой пояс» → `(GMT+03:00) Москва`. Файл `appsscript.json` заменять не нужно.
4. **Параметры проекта → Свойства скрипта** → добавьте:
   - `FIREBASE_API_KEY` — `apiKey` из шага 1.4
   - `SERVICE_ACCOUNT_JSON` — всё содержимое JSON-файла из шага 1.6
   - `ALLOWED_EMAILS` — три почты через запятую
   - `TELEGRAM_BOT_TOKEN` — необязательно (см. ниже)
5. Выберите функцию **apexSetup** → «Выполнить» → разрешите доступ («Дополнительные настройки → Перейти на страницу проекта»). В журнале должно появиться «Готово». Это создаёт триггер `apexTick` раз в 5 минут и ночной бэкап `apexBackup`.
6. **Начать развертывание → Новое развертывание** → тип «Веб-приложение» → «Запуск от имени: меня», «Доступ: Все» → «Развернуть». Скопируйте URL вида `https://script.google.com/macros/s/…/exec` — это `VITE_APPS_SCRIPT_URL`.

После правок кода делайте «Управление развертываниями → Изменить → Новая версия», иначе адрес продолжит отдавать старый код.

### 3. GitHub

1. Создайте репозиторий `apex-hub` и загрузите в него эту папку:
   ```bash
   git init && git add . && git commit -m "APEX Hub"
   git branch -M main
   git remote add origin https://github.com/ЛОГИН/apex-hub.git
   git push -u origin main
   ```
2. **Settings → Secrets and variables → Actions → Variables** → добавьте все `VITE_…` из `.env.example` (кроме `VITE_BASE` — его ставит сборка).
3. **Settings → Pages → Source: GitHub Actions**.
4. Вкладка **Actions** → дождитесь зелёной галочки. Адрес: `https://ЛОГИН.github.io/apex-hub/`.
5. В Firebase → **Authentication → Settings → Authorized domains** добавьте `ЛОГИН.github.io`.

GitHub Pages бесплатен только для **публичного** репозитория. Секретов в коде нет: ключи веб-приложения Firebase публичные по задумке, данные защищают правила Firestore и вход. Если репозиторий нужен закрытым — используйте Firebase Hosting (ниже).

**Зеркало на Firebase Hosting** (`https://ПРОЕКТ.web.app`, полезно, если GitHub в России опять будет тормозить): добавьте в **Secrets** `FIREBASE_SERVICE_ACCOUNT` — JSON сервисного аккаунта. Workflow `firebase-hosting.yml` начнёт выкладывать сайт и туда.

Локальный запуск: `cp .env.example .env`, заполнить, затем `npm install` и `npm run dev`.

### 4. На телефоны

- **iPhone:** откройте адрес в **Safari** → «Поделиться» → «На экран „Домой“» → запустите APEX с иконки → войдите → **Настройки → Уведомления → Включить**. Push на iPhone работает только так (iOS 16.4+), из вкладки браузера — нет.
- **Android:** Chrome → ⋮ → «Установить приложение» → войти → включить уведомления.
- **Компьютер:** Chrome/Edge → значок установки в адресной строке.

Вход запоминается на устройстве, повторно пароль не спрашивается. Каждое устройство включает push отдельно. Проверка: **Настройки → Проверка → Через сервер** — push придёт в течение 5 минут.

### 5. По желанию

**Виджет на iPhone.** Настройки → «Виджет на экран» → «Создать личный ключ». Установите Scriptable из App Store, создайте скрипт из `backend/widget/apex-widget.js`, вставьте в первую строку свою ссылку, добавьте виджет Scriptable на экран.

**Дубль уведомлений в Telegram.** Создайте бота у @BotFather, токен — в свойство `TELEGRAM_BOT_TOKEN`. Каждый пишет боту `/start`, узнаёт свой chat id у @userinfobot и вписывает его в Настройках приложения.

## Как работают напоминания

- У задачи со сроком выбирается «Напомнить»: в момент срока, за 15 мин, 1 ч, 3 ч, 1 день, 2 дня. Если время не указано, отсчёт идёт от 9:00 дня срока.
- Приложение записывает момент напоминания `remindAt`. Apps Script раз в 5 минут находит наступившие, шлёт push исполнителям и очищает поле. Точность — до 5 минут.
- Когда вас добавляют в задачу, приходит push «Серафим добавил вас в задачу».
- Утренний список приходит в выбранное время: задачи на сегодня, число просрочек, тренировки дня, сколько игроков не оплатили. На иконке приложения — число задач на сегодня.

## Бэкапы

Каждую ночь около 03:00 Apps Script сохраняет задачи, события, страницы и профили в JSON-файл на Google Диск, в папку «APEX Hub — бэкапы». Хранятся последние 30 дней, более старые копии уходят в корзину Диска. Сделать копию вручную можно, запустив функцию `apexBackup` в редакторе Apps Script. Google-таблицу бэкапить не нужно: у неё есть «Файл → История версий».

## Структура проекта

```
src/
  pages/          Сегодня, Задачи, Календарь, Клуб, База знаний, Настройки, Вход
  components/     оболочка, редакторы задач и событий, графика Summit Core
  lib/backend/    firebase.js — боевой режим, demo.js — демо в браузере
  lib/club.js     запросы к Google-таблице
  lib/quick.js    разбор фраз «завтра в 15:00 @кузьма !»
  sw.js           service worker: офлайн и push
backend/
  apps-script/    Code.gs + appsscript.json
  firestore.rules правила доступа
  widget/         виджет для Scriptable
```

## Что можно добавить дальше

- Повторяющиеся задачи (еженедельная сверка оплат, отчёт в конце месяца).
- Комментарии и упоминания внутри задач, история изменений.
- Автозадачи из таблицы: новая заявка → задача «Связаться» ответственному; неоплата к 5 числу → задача «Напомнить родителю».
- Импорт расписания из листа «Расписание» и отметка «Проведена / Отменена».
- Отчёт месяца: выручка, посещаемость по игрокам, конверсия заявок в клиентов.
- Раздел «Школы» поверх листа «Школы — расширение APEX» как CRM переговоров.
