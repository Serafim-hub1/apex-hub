# APEX Hub — инструкции для Claude

Командный центр баскетбольного клуба APEX: задачи, календарь, база знаний, оплаты и посещаемость из Google-таблицы.
Пользователи — Серафим, Кузьма, Антон. Общаемся по-русски, разговорным языком.

## Этот файл — память проекта. Обновляй его сам
Этот файл читается в начале каждой сессии, а история чата — нет. Поэтому всё важное, что останется верным и через месяц, записывай сюда **в том же PR**, где сделана правка, без напоминаний.
- **Записывай:** новые листы/колонки таблицы или их смысл, решения по оплатам и правилам клуба, новые разделы приложения, изменения выкладки/секретов/триггеров, грабли, на которые наступили («не делай X, потому что Y»).
- **Не записывай:** мелкие правки интерфейса, исправленные баги без урока, ход работы, планы.
- Правь существующую строку, а не добавляй новую рядом. Устаревшее — удаляй.
- Держи файл коротким (≤ ~80 строк): он загружается в каждую сессию и тратит лимит. Одна мысль — одна строка.
- В описании PR одной строкой: «CLAUDE.md: что обновлено» или «CLAUDE.md: без изменений».

## Экономия лимитов (важно)
- Лимиты обновляются раз в неделю — работай экономно.
- Отвечай коротко: что сделано, что проверить, ссылка на PR. Без пересказа кода и шагов.
- Читай только нужные файлы (карта ниже), не изучай весь проект заново.
- Проверка по умолчанию — `npm run build`. Тесты в браузере со скриншотами — только по просьбе или при изменении интерфейса форм.
- Правки, присланные списком, делай одним PR.

## Как выкладываются изменения
- Никогда не пушить в `main`. Ветка → pull request → Серафим нажимает Merge.
- Merge в `main` → «Deploy to GitHub Pages» пересобирает сайт https://serafim-hub1.github.io/apex-hub/
- Изменение `backend/apps-script/Code.gs` → «Deploy Apps Script» (clasp) сам кладёт код в файл `APEX_Hub` проекта таблицы и обновляет развёртывание на том же адресе.
- В проекте Apps Script есть чужой файл `Код.gs` (onEdit для «Реестра ID») — его не трогать и не дублировать функции из него.
- Весь код скрипта живёт внутри `APEX_HUB`; наружу торчат только `doPost`, `doGet`, `apexSetup`, `apexTick`, `apexBackup`.
- `APEX_Hub.gs` в редакторе Apps Script руками не править — перезапишется при деплое. Деплой скрипта: секрет `CLASPRC_JSON`, переменная `APPS_SCRIPT_ID`.
- Триггеры: `apexTick` каждые 5 мин (напоминания, push, утренний список), `apexBackup` ~03:00 (JSON на Диск, папка «APEX Hub — бэкапы», 30 дней).
- PWA: после выкладки старые файлы сборки удаляются, поэтому ошибка динамического `import()` = устаревшая версия → `reloadOnce()` из `src/lib/reload.js`. Новые `import()` оборачивай так же. Обновление на телефоне: приложение закрыть полностью и открыть.
- «Deploy to Firebase Hosting» — запасной, без секрета `FIREBASE_SERVICE_ACCOUNT` пропускается.

## Карта кода
- `src/pages/` — Today, Tasks, Calendar, Club (оплаты, посещения, заявки), Notes, Settings, Login
- `src/components/` — Layout (меню, ⌘K), Tasks (редактор задачи, быстрый ввод), EventEditor, ui, Brand
- `src/lib/store.jsx` — данные и действия; `lib/backend/firebase.js` — боевой режим, `lib/backend/demo.js` — демо в браузере
- `src/lib/club.js` — запросы к таблице + демо-данные таблицы; `lib/quick.js` — разбор «завтра в 15:00 @кузьма !»
- `src/styles/app.css` — стиль Summit Core (токены цветов в начале файла); `src/sw.js` — офлайн и push
- `backend/apps-script/Code.gs` — мост к таблице, напоминания, утренний список, ночной бэкап на Диск
- `backend/firestore.rules` — доступ только трём почтам

## Данные — не сломать
- Firestore: `users`, `tasks`, `events`, `notes`, `outbox`, `devices`. Меняя структуру полей, оставляй совместимость со старыми записями.
- Таблица: скрипт ищет листы по названию и колонки по номеру. Листы: «Игроки», «Оплаты», «Журнал оплат», «Посещаемость — Junior/Взрослые», «Заявки», «Справочники», «Лига u14/u16».
- «Журнал оплат»: A, B, C, E — формулы ARRAYFORMULA на весь лист, поэтому `getLastRow()` врёт — ищи строки по заполненному ФИО (колонка D).
- Разовое занятие и абонемент — независимые оплаты, разовые в абонемент НЕ зачитываются. Статуса «Разовые» нет (с 10.11.2026): «Оплаты» E2 — есть абонемент в месяце → «Оплачен», иначе «Не оплачен»; L2 — без ⚠, если в месяце есть разовые.
- Цены по умолчанию в форме (сумму можно поправить): разовое Junior 1600 / взрослые («Джокеры») 2600; 1 раз/нед. 9000, 2 раза/нед. 11500, 3 раза/нед. 14500.
- Имена в «Игроках» бывают с пробелом на конце — в журнал писать имя ровно как в листе.
